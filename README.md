
# AI Health Prediction System

An AI-powered health prediction application built using Python and Streamlit.

## Technologies Used
- Python
- Streamlit
- SQLite
- AI / Machine Learning

## Project Structure
- `app.py` – Main application
- `database.py` – Database operations
- `health_ai.py` – Health prediction logic
- `requirements.txt` – Project dependencies

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/KoushkiDubey/AI-Health-Prediction-System.git
   ```

2. Navigate to the project folder:

   ```bash
   cd AI-Health-Prediction-System
   ```

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the application:

   ```bash
   streamlit run app.py
   ```
